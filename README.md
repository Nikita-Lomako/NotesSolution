NotesSolution
Описание
NotesSolution — это эффективное и надежное backend-приложение для работы с заметками.
Сервис предоставляет RESTful API для управления заметками, поддерживает работу с изображениями,
аутентификацию пользователей и расширенные возможности поиска и фильтрации.

Функционал Web API
1.Получение списка всех заметок с поддержкой поиска, фильтрации, сортировки и пагинации
2.Получение определённой заметки по её Id
3.Создание новой заметки
4.Обновление информации о существующей заметке
5.Удаление заметки
6.Работа с изображениями (загрузка, хранение и получение изображений для заметок локально)
7.Регистрация и аутентификация пользователей (JWT)
8.Валидация входящих данных (DTO)
9.Глобальная обработка ошибок через middleware

Технологический стек
C# & .NET 8 — кроссплатформенный язык и фреймворк для серверных приложений
ASP.NET Core — построение RESTful API
Entity Framework Core — ORM для работы с базой данных
PostgreSQL — реляционная база данных
xUnit — модульное тестирование
Docker & Docker Compose — контейнеризация и развертывание

Дополнительные возможности
JWT-аутентификация и авторизация
Валидация DTO с помощью FluentValidation
Гибкий поиск, фильтрация, сортировка и пагинация заметок
Глобальная обработка ошибок
Чистая архитектура и следование принципам SOLID
Легкое развертывание с помощью Docker и Docker Compose

Быстрый старт
1.Клонируйте репозиторий
2.Настройте переменные окружения: Укажите строку подключения к PostgreSQL и секрет для JWT в appsettings.json или через переменные окружения(.env).
3.Запустите проект через Docker Compose
4.API будет доступен по адресу: https://localhost:8081
5.Swagger UI: Доступен по адресу /swagger для тестирования и ознакомления с API.
